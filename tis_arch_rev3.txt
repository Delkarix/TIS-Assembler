REGISTER ALLOCATION:
    A0-A3 and T0-T7 are temp variables and thus must be preserved by the caller.
    S0-S7 and DATA are storage variables and thus must be saved and restored by the callee

    STACK can be used for temporary storage, assembler temporaries, and macros
    
    NULL, ONE, TWO, FOUR, EIGHT, SIXTEEN, and NEG_ONE always return their hardcoded respective values and cannot be written to.
    For convenience, the 8-bit integers 0, 1, 2, 4, 8, 16, and -1 (0xFFFFFFFF) are stored at their corresponding addresses in memory
    (e.g. dereferencing the number 8 will return the number 8).

    ERROR lists an error that is set on certain behavior (e.g. division-by-zero)
    ERROR_ADDR lists the address this was flagged on.

    SYSTEM_IO is used for system calls to the emulator.
    The system call ID is first written to SYSTEM_IO and then all arguments are subsequently written.
    Return values are read from SYSTEM_IO after completion.
    Attempting to read from SYSTEM_IO before sending all arguments, sending invalid syscalls, or sending incorrect data will flag an ERROR.

    All registers are 32-bit.
    All instructions are 4 bytes wide and 32-bit aligned.


GENERAL INSTRUCTION FORMAT:
        1 bit Opcode (0)        3 bits extended opcode (func)        1 bit USE_LITERAL

        5 bit DEST_REG        5 bit REG1
        
        [1 bit SHIFT    16 bit LITERAL]
                OR
        [5 bit REG2     5 bit SHIFT_REG     2 bit LOGICAL_OP     5 bit LOGICAL_REG]

        SHIFT=1 means that the LITERAL should be placed in the upper 16-bits of DEST_REG

        SHIFT_REG specifies a register whose value is applied as a signed shift to REG2
        LOGICAL_REG is a register to AND, OR, XOR, or NAND with REG2
        LOGICAL_OP = 00      => AND
                   = 01      => OR
                   = 10      => XOR
                   = 11      => NOT_ADD         => NOTs REG2 and adds LOGICAL_REG


        Formula is basically:

        DEST_REG = REG1 ~ LITERAL

            OR

        DEST_REG = REG1 ~ ((REG2 << SHIFT_REG) LOGICAL_OP LOGICAL_REG)

CMP INSTRUCTION FORMAT
    1 bit Opcode (1)    2 bits comparison operator (func)    5 bit DEST_REG
    5 bit COMP_REG1        5 bit COMP_REG2        5 bit SELECTION_REG1    5 bit SELECTION_REG2
    2 bit Deref_comp  2 bit Deref_dest


    CMP~ DEST_REG, COMP_REG1, COMP_REG2, SELECTION_REG1, SELECTION_REG2:
        if (COMP_REG1 ~ COMP_REG2) {
            DEST_REG = SELECTION_REG1;
        }
        else {
            DEST_REG = SELECTION_REG2;
        }

    The Dereference masks specify whether a given pair of registers should be memory-dereferenced according to the corresponding bits set.
    Deref_comp corresponds to COMP_REG1 and COMP_REG2
    Deref_dest corresponds to DEST_REG. This means that the corresponding bytes from the chosen SELECTION_REG will be written to the address specified by DEST_REG
    
    00 = No dereference
    01 = 1 byte
    10 = 2 bytes
    11 = 4 bytes

FMULADD INSTRUCTION FORMAT
    
        2 bit Opcode (01)     1 bit CONVERSION    3 bit RECIPROCAL     3 bit INTERPRETATION     2 bit NEGATE    1 bit MODE

    
        5 bit DEST_REG        5 bit REG1    5 bit REG2    5 bit REG3

Opcode:
    0: Arithmetic
        Extension:
            000: ADD
            001: MUL        =>
            010: DIV
            011: MOD
            1xx: FMULADD        =>    Floating Point Fused Multiply-Add
                            Can perform the majority of common floating-point operations.
                            RECIPROCAL bits[2,0] correspond to REG1, REG2, and REG3.
                            If the corresponding bit is set, the reciprocal of the register is used. Otherwise, the register's original value is used.

                            If the CONVERSION bit is set, the result will be converted to an integer (floor) before being stored in DEST_REG

                            INTERPRETATION determines whether the corresponding REG1, REG2, and REG3 are interpreted as integers and converted to floats (0) or directly interpreted bitwise as floats (1)

                            NEGATE[0] means to negate REG1
                            NEGATE[1] means to negate REG3

                            MODE:
                                0 => REG1*REG2 + REG3
                                1 => REG1^REG2 + REG3   (exponent)
            

    1: Comparison (CMP)
        Extension:
            00: == (CMPE)        => Sets DEST_REG to SELECTION_REG1 if COMP_REG1 == COMP_REG2 and SELECTION_REG2 if COMP_REG1 != COMP_REG2
            01: <  (CMPGU)        => Sets DEST_REG to SELECTION_REG1 if unsigned COMP_REG1 < unsigned COMP_REG2 and SELECTION_REG2 if unsigned COMP_REG1 >= unsigned COMP_REG2
            10: <  (CMPG)        => Sets DEST_REG to SELECTION_REG1 if signed COMP_REG1 < signed COMP_REG2 and SELECTION_REG2 if signed COMP_REG1 >= signed COMP_REG2
            11: FP < (FCMPG)    => Compares COMP_REG1 and COMP_REG2 via < floating-point operations
                

STACK:
    Can be used as temp assembler storage.
    When the STACK is requested more than once in a single instruction, the value is filled in left-to-right.
    For instance:
        MOV STACK, `2
        MOV STACK, `3
        SUB T0, STACK, STACK

    Would expand to
        SUB T0, `3, `2

    STACK is only popped when actually read from.
    For instance:
        CMPE T3, T0, T1, NULL, STACK

        If T0 == T1, then T3 = 0 and STACK is unaffected.
        If T0 != T1, then T3 = STACK and the value on top of the STACK is popped.

GRAMMAR:
    Program := StatementList
    StatementList := PreprocessorInstructionLabel [Comment] \n StatementList | E
        -> or potentially just List<PreprocessorInstructionLabel> depending on parsing strategy
    PreprocessorInstructionLabel := Preprocessor | Instruction | Label | E
    Label := ":" ALPHANUMERIC_IDENTIFIER
    Preprocessor := "." ALPHANUMERIC_IDENTIFIER PreprocessorPost
    PreprocessorPost := ALPHANUMERIC_IDENTIFIER | NUMBER | Label
    Comment := # ASCII_EXCLUDE_NEWLINE
    Instruction := ALPHANUMERIC_IDENTIFIER ArgsList
    ArgsList := Argument ArgsList | E
    Argument := Register | Literal | Label
    Register := ALPHANUMERIC_IDENTIFIER
    Literal := "`" NUMBER



SYSCALLS:
    0: HALT            =>    Stops the program
    1: READ_CHAR        =>    Reads a keyboard press and sets REG1 to the ASCII value (ENTER = 0xA)
    2: WRITE_CHAR        =>    Writes the value in REG1 as an ASCII character to the emulator's STDOUT
    3: LOAD_BLOCK        =>    Opens the persistent data storage file and loads a block specified with the index address specified in REG2 and length specified by REG3 into the memory specified by the address specified REG1.
    4: MALLOC        =>    Allocates a block of memory based on a bytesize specified in REG1 and sets REG1 to the pointer to the start of the block
    5: FREE            =>    Frees the block of memory based on the address specified in REG1
    6: RANDOM        =>    Sets REG1 to a random 16-bit integer
    7: FILL_STACK        =>    Pushes the value in REG1 to the STACK as many times as specified in REG2
    8: CYCLES        =>    Sets REG1 to the number of cycles that the virtual CPU has completed since activated
    9: SLEEP        =>    Sleeps the number of milliseconds specified in REG1
    10: CREATE_THREAD    =>    Creates a new thread that starts at the address specified in REG1. REG1 is set to the thread's ID
    11: KILL_THREAD        =>    Immediately kills the thread with the ID specified by REG1.
    12-63: Undefined

PREPROCESSOR INSTRUCTIONS:
    .EXPORT <:LABEL>    =>    Marks the subsequent label as being public to the linker
    .INCLUDE <"file">    =>    Similar to C's #include, directly injects the contents of "file.tis" into the current place in the file.
    .LINK <"file.tis">    =>    Tells the assembler to assemble and link the given file as well if it hasn't been done so already
    .IMPORT <:LABEL>    =>    States that a given label is to be linked in later
    .ZERO <LITERAL>        =>    Statically allocates <LITERAL> bytes equaling 0.
    .8 <LITERAL>        =>    Statically allocates a single byte with the value LITERAL
    .16 <LITERAL>        =>    Statically allocates 2 bytes with the value LITERAL
    .32 <LITERAL>        =>    Statically allocates 4 bytes with the value LITERAL
    .STRING <"string">    =>    Statically allocates an ASCII string terminated by 0.
    .8[] { <LITERAL...> }    =>    Hexadecimal array of bytes
    .16[] { <LITERAL...> }    =>    Hexadecimal array of 16-bit integers
    .32[] { <LITERAL...> }    =>    Hexadecimal array of 32-bit integers
    .MACRO <name> <PARAMS, ...> {
        <INSTRUCTIONS...>
    }
        =>     Defines a macro with a name and parameters that expands to a set of instructions
            Many macros are defined by default in base.tis

                .MACRO ADD_AND_PRINT FORMAT_STR, REG_ARG, SOME_LITERAL {
                    ADD A1, REG_ARG, SOME_LITERAL

                }

                                            MOV A0, :PRINT_STR

EXAMPLE: Integer Sqrt Algorithm

.LINK "stdio.tis"    # Tells the assembler to assemble stdio.tis and link it if it has not already.
.IMPORT :STDIO.PRINT_UINT8

.EXPORT :SQRT
    # A0 = Number to square root
    # A1 = Number of iterations

    MOV T0, A0            # Save original A to C
    LOAD_IMM16 A2, :LOOP

    :LOOP
    DIV T1, T0, A0        # T1 = a/x_n
    ADD A0, A0, T1        # A0 = x_n + a/x_n
    SRL A0, A0, `1        # A0 = (x_n + a/x_n)/2

    SUB A1, A1, `1
    CMPGU PC, NULL, A1, A2, STACK

.EXPORT :MAIN
    MOV A0, `12345
    MOV A1, `10
    CALL_REL :SQRT
    CALL :STDIO.PRINT_UINT8    # Included by stdio.tis
    SYSCALL NULL            # HALT

EXAMPLE: Float32 Sqrt Algorithm
.LINK "stdio.tis"    # Tells the assembler to assemble stdio.tis and link it if it has not already.
.IMPORT :STDIO.PRINT_FLOAT32

.EXPORT :SQRTF32
    # A0 = Number to square root
    # A1 = Number of iterations

    MOV SYSTEM_IO, `7       # FILL_STACK_LITERAL
    MOV SYSTEM_IO, :LOOP
    MOV SYSTEM_IO, A1       # fill the STACK with 10 instances of LOOP.

    MOV T0, A0              # Save original A0 to T0

    :LOOP
    FMULADD A0, T0, `1/A0, A0           # A0 = a/x_n + x_n
    FMULADD A0, A0, `1/F:TWO, NULL      # A0 = (a/x_n + x_n)/2

    MOV PC, STACK

.EXPORT :MAIN
    # Load float 12345.0
    MOV A0, `58368
    MOV_HI A0, `17984
    MOV A1, `10
    CALL_REL :SQRTF32
    CALL :STDIO.PRINT_FLOAT32   # Included by stdio.tis
    MOV SYSTEM_IO, NULL         # HALT





EXAMPLE: Add a list of numbers
.EXPORT :ADD_8_VEC
    # A0 = Address of the first array
    # A1 = Address of the second array
    # A2 = Address of the output array
    # A3 = Count

    MOV T2, :LOOP

    # Adds the two arrays in reverse to reduce instructions
    :LOOP
    SUB A3, A3, `1
    LOAD8 T0, A0, A3
    LOAD8 T1, A1, A3
    ADD T0, T0, T1
    STORE8 T0, A2, A3

    CMPGU PC, NULL, A3, T2, STACK
        

.EXPORT :MAIN
    MOV A0, :ARR1
    MOV A1, :ARR2
    MOV A2, :ARR3
    LOAD8 A3, :COUNT
    CALL_REL :ADD_8_VEC
    SYSCALL NULL


:COUNT .8 `9
:ARR1 .8[] { `1, `2, `3, `4, `5, `6, `7, `8, `9 }
:ARR2 .8[] { `9, `8, `7, `6, `5, `4, `3, `2, `1 }
:ARR3 .ZERO `9
